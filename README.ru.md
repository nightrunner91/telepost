## Обзор проекта

Telepost — это минималистичный и надёжный планировщик, который отправляет фотографии из локальной папки в Telegram-чат от вашего имени. Он создан для авторов, администраторов и разработчиков, которым нужен автономный способ публиковать визуальный контент в заданные ежедневные интервалы.

Планировщик периодически проверяет, была ли уже отправлена сегодняшняя квота, и если текущее время находится внутри настроенного окна, выбирает самые старые неотправленные изображения, рандомизирует время их отправки и публикует по одному. Каждое успешно отправленное фото логируется и перемещается в отдельную папку `sent/`, поэтому один и тот же файл никогда не будет опубликован дважды.

Если приложение запускается после окончания окна отправки (например, компьютер был выключен в нужное время), а сегодняшняя квота ещё не выполнена, оно автоматически отправляет пропущенные фото сразу. Догоняющая отправка работает только в пределах текущего дня: после полуночи пропущенный день считается прошедшим и не восстанавливается.

## Возможности

- **Публикация от имени пользователя** через личный Telegram-аккаунт.
- **Настраиваемое ежедневное окно** и количество фото в день.
- **Случайное время отправки** внутри окна для естественной активности.
- **Догоняющая отправка** пропущенных фото в тот же день, если приложение запустилось после окна.
- **Дедупликация** через постоянный JSON-лог отправленных фото.
- **Автоматическое управление файлами**: отправленные изображения перемещаются в `sent/`.
- **Готовность к Docker** с постоянным хранением сессии.
- **Тестовое покрытие** с `pytest` для основной логики планирования и отслеживания.

## Быстрый старт

### Требования

- Локально установленный Python 3.11 или новее, либо Docker и Docker Compose.
- Аккаунт Telegram.
- `api_id` и `api_hash`, полученные на [my.telegram.org/apps](https://my.telegram.org/apps).
- `chat_id` целевого чата или пользователя. Перешлите сообщение из целевого чата боту [@userinfobot](https://t.me/userinfobot), чтобы получить его.

### Установка

```bash
git clone https://github.com/nightrunner91/telepost.git
cd telepost
```

Для локальной разработки:

```bash
python -m venv .venv
source .venv/bin/activate  # В Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### Запуск

```bash
# Скопируйте пример конфигурации и заполните свои данные
cp config.yaml.example config.yaml
# Отредактируйте config.yaml, указав api_id, api_hash, phone и chat_id

# Авторизуйтесь один раз
python auth.py

# Запустите планировщик
python main.py
```

## Использование

### Локальный запуск

После авторизации запустите планировщик командой:

```bash
python main.py
```

Планировщик проверяет каждые 5 минут, находится ли текущее время внутри настроенного окна отправки и выполнена ли сегодняшняя квота. Если оба условия истинны, начинается отправка фото. Если приложение запустилось после окончания окна, а квота за сегодня ещё не выполнена, пропущенные фото отправляются сразу, не дожидаясь следующего дня.

### Запуск через Docker

```bash
# Скопируйте и отредактируйте конфигурацию
cp config.yaml.example config.yaml

# Опционально: подготовьте .env для неинтерактивного ввода кода
cp .env.example .env

# Авторизуйтесь интерактивно (один раз)
docker compose run --rm telepost python auth.py

# Запустите планировщик в фоновом режиме
docker compose up -d
```

> [!NOTE]
> Telegram-сессия и лог отправленных фото сохраняются в Docker-томе `telepost_data`, поэтому авторизация требуется только один раз. Фотографии по-прежнему управляются из папки `photos/` на хосте.

## Конфигурация

Создайте `config.yaml`, скопировав `config.yaml.example`, и измените значения:

```yaml
api_id: 12345678
api_hash: "your_api_hash_here"
phone: "+1234567890"
chat_id: 987654321              # id целевого чата или пользователя (целое число)
photos_dir: "./photos/incoming" # исходная папка
sent_dir: "./photos/sent"       # папка для уже отправленных фото
sent_log: "./data/sent_photos.json"
schedule:
  start_hour: 8
  start_minute: 10
  end_hour: 8
  end_minute: 20
photos_per_day: 3
catch_up_missed: true
```

| Поле | Описание | Значение по умолчанию |
|------|----------|----------------------|
| `api_id` | App ID приложения Telegram из my.telegram.org | обязательно |
| `api_hash` | App Hash приложения Telegram из my.telegram.org | обязательно |
| `phone` | Номер телефона, привязанный к аккаунту Telegram | обязательно |
| `chat_id` | ID целевого чата или пользователя | обязательно |
| `photos_dir` | Папка с изображениями для отправки | `"./photos/incoming"` |
| `sent_dir` | Папка, куда перемещаются отправленные изображения | `"./photos/sent"` |
| `sent_log` | JSON-лог отправленных фото | `"./data/sent_photos.json"` |
| `schedule.start_hour` | Час начала окна | `7` |
| `schedule.start_minute` | Минута начала окна | `0` |
| `schedule.end_hour` | Час окончания окна | `8` |
| `schedule.end_minute` | Минута окончания окна | `0` |
| `photos_per_day` | Максимальное количество фото в день | `3` |
| `catch_up_missed` | Сразу отправлять пропущенные за сегодня фото, если приложение запустилось после окна | `true` |

> [!IMPORTANT]
> Храните `config.yaml`, `.env` и директорию `data/` вне системы контроля версий. Они уже добавлены в `.gitignore`.

## Справочник API

Telepost состоит из небольших модулей с чётко разделённой ответственностью. Ниже описаны ключевые публичные интерфейсы.

### `config.load_config(path: str | Path = "config.yaml") -> dict`

Загружает и валидирует `config.yaml`. Выбрасывает `ConfigError`, если отсутствуют обязательные поля или `chat_id` не является целым числом.

### `sender.generate_random_times(start_hour, start_minute, end_hour, end_minute, count) -> list[time]`

Возвращает `count` уникальных отсортированных значений `datetime.time` внутри настроенного окна.

### `sender.send_photo(client, chat_id, photo_path, sent_dir) -> bool`

Отправляет одно изображение через клиент Telethon и при успехе перемещает его в `sent_dir`.

### `tracker.PhotoTracker`

Постоянный помощник для управления логом отправленных фото.

| Метод | Описание |
|-------|----------|
| `mark_sent(path)` | Помечает фото как отправленное сегодня. |
| `is_sent(path) -> bool` | Проверяет, было ли фото уже отправлено. |
| `get_today_count() -> int` | Возвращает количество фото, отправленных сегодня. |
| `get_pending_photos(photos_dir, count) -> list[str]` | Возвращает самые старые неотправленные фото, но не более `count`. |

### `auth.authenticate(code: str | None = None)`

Запускает сессию Telethon и авторизуется в Telegram. Если `code` не передан, запрашивает код интерактивно. Файл сессии сохраняется в `data/telegram_session.session`.

### `main.main_loop()`

Точка входа планировщика. Подключается к Telegram, проверяет авторизацию и запускает бесконечный цикл планирования. Если цикл запускается после окончания окна отправки и сегодняшняя квота не выполнена, пропущенные фото отправляются сразу (управляется параметром `catch_up_missed`).

## Разработка

### Запуск тестов

```bash
pytest tests/ -v
```

### Структура проекта

```
telepost/
├── main.py              # точка входа планировщика
├── auth.py              # одноразовая авторизация в Telegram
├── sender.py            # выбор, фильтрация и отправка фото
├── tracker.py           # постоянное отслеживание отправленных фото
├── config.py            # загрузчик и валидатор конфигурации
├── config.yaml.example  # шаблон конфигурации
├── .env.example         # шаблон переменной окружения для кода
├── docker-compose.yml   # определение сервиса Docker Compose
├── Dockerfile           # определение образа контейнера
├── requirements.txt     # зависимости Python
├── photos/              # папки с фото
│   ├── incoming/        # поместите изображения сюда
│   └── sent/            # сюда перемещаются отправленные изображения
├── data/                # runtime-данные (сессия, лог)
└── tests/               # набор тестов pytest
    ├── test_main.py
    ├── test_sender.py
    └── test_tracker.py
```

## Отказ от ответственности

Автоматизация личного Telegram-аккаунта может нарушать Условия использования Telegram. Используйте этот инструмент на свой страх и риск и только для легитимного управления каналами или чатами, которыми вы владеете. Не используйте его для спама, преследований или нежелательных сообщений.
